# Contact Form

An accessible HTML contact form built for the [roadmap.sh Contact Form project](https://roadmap.sh/projects/contact-form).

## Requirements Covered

- A `form` with `action` and `method="post"`
- Full name text input with `required`
- Email input with `type="email"` and `required`
- Subject select with multiple options
- Required message textarea with `minlength`
- Radio buttons grouped inside a `fieldset` with a `legend`
- Optional newsletter checkbox
- Real labels paired with every form control
- Submit button with clear text
- Browser validation using HTML attributes
- Required head metadata
- No CSS
- No JavaScript

## Project URL

[View the live Contact Form](https://sunilkumarkv.github.io/full-stack-projects/FRONTEND/html/Contact-Form/)

## Run Locally

Open `index.html` in a browser or use VS Code Live Server.

## Testing the Request

The form uses a placeholder action URL. Use browser DevTools → Network → Preserve log, then submit the form to inspect the request and the submitted name/value pairs.
