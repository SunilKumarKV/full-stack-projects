# Pricing Comparison Table

A single-page accessible HTML pricing comparison table built for the [roadmap.sh Pricing Comparison Table project](https://roadmap.sh/projects/pricing-comparison-table).

## Requirements Covered

- Semantic `<header>`, `<main>`, and `<footer>` page structure
- Real HTML `<table>` with `<caption>`, `<thead>`, and `<tbody>`
- Three subscription plans compared side by side
- `scope="col"` on column headers
- `scope="row"` on row headers
- Meaningful merged cell using `colspan`
- `<title>`, charset, and viewport metadata
- No CSS or JavaScript
