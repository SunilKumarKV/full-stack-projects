# Basic HTML Website

A simple multi-page HTML-only website built for the [roadmap.sh Basic HTML Website project](https://roadmap.sh/projects/basic-html-website).

## Pages

- Home
- Projects
- Articles
- Contact

## Requirements Covered

- Semantic HTML structure
- Multiple pages
- Navigation bar on every page
- Internal page links
- SEO meta tags on every page
- Contact form with name, email, subject, and message fields
- No CSS or JavaScript styling

## Project URL

[View the live Basic HTML Website](https://sunilkumarkv.github.io/full-stack-projects/FRONTEND/html/Basic-HTML-Website/)

## Run Locally

Open `index.html` in a browser, or use VS Code Live Server.
