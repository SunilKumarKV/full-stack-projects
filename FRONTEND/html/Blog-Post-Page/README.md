# Blog Post Page

A single semantic HTML blog post built for the [roadmap.sh Blog Post Page project](https://roadmap.sh/projects/blog-post-page).

## Requirements Covered

- Single HTML page with `header`, `main`, `article`, and `footer`
- One `h1` with logical `h2` and `h3` subsections
- Paragraphs, ordered/unordered lists, blockquote with citation, inline code, and code block
- Meaningful `em` and `strong` elements
- Descriptive links
- `figure`, `img` with useful `alt`, and `figcaption`
- Title, charset, viewport, and meta description
- No CSS or JavaScript
