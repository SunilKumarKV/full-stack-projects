# Photo Showcase

An HTML-only photo showcase project built for the [roadmap.sh Photo Showcase](https://roadmap.sh/projects/photo-showcase) challenge.

## Requirements covered

- Semantic `header`, `main`, and `footer` structure
- Seven images in the main content
- Every image includes `src`, useful/intentional `alt`, `width`, and `height`
- Five images use `figure` and `figcaption`
- One decorative image uses `alt=""`
- Embedded `video` includes `controls`, a `poster`, and fallback text
- `title`, charset, and viewport metadata
- No CSS or JavaScript, as required by the project
